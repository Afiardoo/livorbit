# livorbit · Life, in every orbit.

Health monitoring and emergency guidance for astronauts on long-duration missions.
NASA Space Apps Challenge 2026 · *Create Health Monitoring Software for Astronauts on Space Missions*.

## What it does
| Screen | Purpose |
|---|---|
| **Crew overview** | NOMINAL / CAUTION / WARNING for each crewmember, crew alerts, and the mission clock with the Earth signal delay |
| **Health status** | Interactive body map (8 systems), NEWS2 early-warning score, vital-sign trends against each astronaut's personal normal, and blood analysis |
| **Daily check-in** | Guided measurements: how to take each one with real ISS equipment, why it matters in space, and what to do if it is off |
| **Mission twin** | Bone density and radiation dose projected over a Mars mission with NASA published rates, plus the effect of exercise and the storm shelter |
| **Emergency** | Chest pain or collapse protocol aware of the communication delay: crew roles, CPR timer, action log, compact report for Earth |
| **NASA data lab** | Real Inspiration4 blood data (NASA OSDR) and what it taught us |
| **Methods & tech** | Engines, data provenance, validation, data-capture architecture, limits and sources |

## Data
- **Real:** NASA OSDR OSD-575 and OSD-569 (SpaceX Inspiration4 metabolic panel and complete blood count), plus the ISS CHeCS Medical Hardware Catalog (device ranges).
- **Synthetic:** a 4-person, 270-day Mars mission generated by `../herramientas/generar_sintetico.py`. Blood baselines come from the real Inspiration4 crew; drifts follow NASA Human Research Program rates. Every synthetic record carries `sintetico: true`, and the UI labels it "Simulated data".

## Engines (`src/engine/`)
- **A · Personal normal:** a z-score against the astronaut's own baseline, recalibrated in flight.
- **B · Trend:** a linear forecast of days until a threshold is crossed.
- **C · Mission twin:** NASA rates for bone loss and radiation.
- **D · NEWS2:** the National Early Warning Score 2.

The Python reference implementation and its validation are in `../herramientas/`, with results in `../VALIDATION.md`.

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/, deployable to any static host
```

## Stack
React 18, TypeScript, Vite, Tailwind CSS 4 and Recharts. Fully client-side and works offline.

## Use of AI
AI assistants helped with research, code and the illustrations. Each generated illustration carries a visible "AI-generated" watermark. Logo, icons and body map are hand-authored SVG redraws.

## Disclaimer
Training and research prototype. Not a medical device and not clinically validated. It does not give drug doses and does not replace the ISS Medical Checklist or the flight surgeon.
